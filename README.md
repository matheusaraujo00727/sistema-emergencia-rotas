# Sistema de Emergência - Cidália

Sistema web para gerenciamento de atendimentos de emergência, permitindo o controle de ocorrências, equipes e recursos operacionais da cidade fictícia de Cidália.

## Tecnologias

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

### Frontend
- Angular
- TypeScript

## Estrutura do Projeto

O sistema segue uma arquitetura cliente-servidor, composta por:

- **Frontend:** Interface web desenvolvida em Angular.
- **Backend:** API REST desenvolvida com Spring Boot.
- **Banco de Dados:** H2 Database para armazenamento dos dados.
- **Arquitetura:** Organização em camadas (Controller, Service e Repository).

## Objetivo

Auxiliar a gestão de atendimentos de emergência por meio do registro de ocorrências, gerenciamento de equipes e acompanhamento operacional em tempo real.
